# ioBroker.samba-solar-track

> [English README](../../README.md)

监视 **Samba Solar Track** 控制器：一款带风暴保护的太阳能组件太阳跟踪器，基于配有 10.1 英寸触摸屏的 ESP32-P4 开发板。适配器在 ioBroker 中显示控制器的状态，并接收设备写入其日志的每一条消息。

设备的硬件和手册（10.1 英寸版本）： <https://github.com/ssbingo/samba-solar-track>。固件仅以编译后的形式提供： <https://firmware.samba-solar.de/>

“Samba”是项目的名称。本适配器与 Samba 文件共享服务（SMB）无关。

## 工作方式

设备是主导。跟踪、风暴保护、限位开关和运行时间监控完全不依赖网络和 ioBroker。适配器只是补充：它在家庭 WLAN 中连接设备（端口 80 上的 HTTP 和 WebSocket），并映射设备报告的内容。如果 ioBroker 或 WLAN 发生故障，跟踪器的工作不受任何影响。

## 项目状态

开发中的早期版本，已发布到 npm，但尚未进入 ioBroker 软件源。已具备：带自动重连的连接、以状态形式呈现的控制器状态、带时间和历史记录的消息、命令（自动、放平停放、确认故障、带安全保持功能的手动驱动）和设备设置（带限值的数值、需在显示屏上确认的提议、初始设置、外观设计），参见[英文 README](../../README.md#commands)。此外还可通过消息适配器发送通知（风暴、故障、风速计、太阳传感器、连接、重启）。自 0.1.1 起，适配器包含六个 vis-2 小部件（“Samba Solar Track”组）：概览、操作、消息、数值、太阳位置和调试程序，采用 vis-2 的设计（Material，跟随 vis-2 的浅色和深色主题），内容和功能与显示屏一致；只需选择适配器实例。说明见[英文 README](../../README.md#vis-2-widgets)。连接和读取已用真实设备测试（固件 0.0.3，2026-10-03）；命令、设置和通知仅用模拟设备测试。 自 0.1.1 起还支持固件 0.7.8 及更早版本的功能：太阳位置、带测试报告的调试程序、带霍尔传感器的指令倾角、同步控制器复位以及通过互联网更新固件；状态说明见[英文 README](../../README.md#states)。

## 要求

- 固件 0.0.1 或更高版本的 Samba Solar Track（协议版本 1），并在显示屏上启用 WLAN
- ioBroker js-controller 6.0.11 或更高版本、admin 8.0.0 或更高版本、Node.js 22 或更高版本

## 配置

| 设置 | 含义 |
| --- | --- |
| 设备地址 | IP 地址或主机名；显示屏在 设置 > 网络 中显示两者。 |
| 端口 | 设备使用端口 80。 |
| 令牌，第 1–4 块 | 设备的令牌：四个并排的字段，每个字段一个 8 字符的块（0-9、a-f）。显示屏在齿轮 > NETWORK、标题“TOKEN FOR THE ADAPTER”下显示：第 1、2 块在第一行，第 3、4 块在第二行；请从左到右输入。输入像密码一样隐藏，输入时点击眼睛图标可显示。字段加密保存，已保存的块保持隐藏：如需修改，请将其完全删除后重新输入。没有令牌时适配器只能读取。错误或不完整的块会标红，字段下方的红色提示行说明原因，并阻止保存；如果错误的令牌仍到达适配器，日志会指出是哪个块。以前单个字段中的令牌（0.0.4 或更早版本）会在 0.0.6 或更新版本首次启动时移入四个字段，随后适配器重启一次；无法使用的旧值不会被移入，并会作为错误报告，直到四个字段填写完整。 |
| 将设备消息写入 ioBroker 日志 | 从哪个级别开始，设备消息也会出现在 ioBroker 日志中。无论如何，所有消息都会保存在 `messages` 下的状态中。 |
| 历史记录中的消息数 | `messages.history` 中的消息数（1 到 500）。 |

## 日志与调试

日志级别、标签以及如何切换日志级别，请参阅[英文 README](../../README.md#logging-and-debugging)。令牌绝不会出现在日志中。

- (ssbingo) 令牌输入：当某个块不完整或错误时，四个字段下方的红色提示行会说明原因；已保存的块可以再次修改（完全删除后重新输入）；在手机上每个字段占满整行宽度；移入旧令牌后，首次启动会在 js-controller 重启适配器之前正常结束（紧凑模式下不再出现第二个连接）；关于旧令牌字段的日志文本更清晰
