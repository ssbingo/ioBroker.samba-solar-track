# ioBroker.samba-solar-track

> [English README](../../README.md)

Відстежує контролер **Samba Solar Track**: сонячний трекер для сонячних модулів із захистом від шторму на платі ESP32-S3 із 7-дюймовим сенсорним дисплеєм. Адаптер показує стан контролера в ioBroker і отримує кожне повідомлення, яке пристрій записує до свого журналу.

Апаратна частина, прошивка та посібник пристрою: <https://github.com/ssbingo/samba-solar-track> (цей репозиторій поки що не є загальнодоступним)

«Samba» — це назва проєкту. Адаптер не має стосунку до файлового сервісу Samba (SMB).

## Як це працює

Головним є пристрій. Стеження, захист від шторму, кінцеві вимикачі та контроль часу роботи діють повністю без мережі та без ioBroker. Адаптер — це доповнення: він підключається до пристрою в домашній мережі WLAN (HTTP і WebSocket на порту 80) і відображає те, що повідомляє пристрій. Якщо ioBroker або WLAN недоступні, у роботі трекера нічого не змінюється.

## Стан проєкту

Рання версія в розробці, не опублікована в npm. Готово: з'єднання з автоматичним перепідключенням, стан контролера у вигляді станів, повідомлення з часом та історією, команди (автоматика, паркування, квитування несправності, ручний привід із контролем присутності) та налаштування пристрою (значення з межами, пропозиції з підтвердженням на дисплеї, початкове налаштування, оформлення), див. [англійський README](../../README.md#commands). Також сповіщення через адаптер повідомлень (шторм, несправності, датчик вітру, датчик сонця, з'єднання, перезапуск). Заплановано: віджети vis-2. Поки перевірено лише на імітації пристрою, **не на реальному обладнанні**.

## Налаштування

| Налаштування | Значення |
| --- | --- |
| Адреса пристрою | IP-адреса або ім'я хоста; дисплей показує їх у налаштування > мережа. |
| Порт | Пристрій використовує порт 80. |
| Токен | Показано на дисплеї в налаштування > мережа > віддалений доступ. Читання працює без токена; він знадобиться для команд. Зберігається в зашифрованому вигляді. |
| Записувати повідомлення пристрою до журналу ioBroker | З якого рівня повідомлення пристрою з'являються також у журналі ioBroker. Усі повідомлення в будь-якому разі зберігаються у станах у `messages`. |
| Повідомлень в історії | Кількість повідомлень у `messages.history` (від 1 до 500). |
